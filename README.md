# Unit Conversions

Performs unit conversions in Laravel

## Installation

You can install the package by adding the following repository:
```php
"repositories": {
    "unit-conversions": {
        "type": "github",
        "url": "https://github.com/Vortech-Group/unit-conversions",
        "options": {
            "symlink": true
        }
    }
},
```

Next you can install it via composer:
```bash
composer require vortech/unit-conversions
```
